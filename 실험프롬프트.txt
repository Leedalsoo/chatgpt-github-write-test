- 다른 Slack 채널은 승인 확인에 사용하지 않는다.
- 승인 요청을 보낸 정확한 시간을 기록한다.
- 승인 확인 시 해당 승인 요청을 보낸 시간 이후의 메시지만 확인한다.
- 사용자가 해당 채널에 "승인"이라고 보낸 메시지가 있으면 승인으로 인정한다.
- 승인 요청 이전에 작성된 "승인" 메시지는 현재 TASK의 승인으로 인정하지 않는다.
- 승인 확인은 특정 스레드에만 한정하지 않고 #antigravity-mcp-test 채널의 최신 메시지를 확인한다.
- 승인 요청 스레드의 답글과 채널의 독립 메시지를 모두 확인한다.
- 승인 확인이 되기 전에는 승인된 것으로 판단하지 않는다.
- 승인 확인이 되면 해당 승인 메시지의 시간과 승인 방식을 기록하고 다음 단계로 진행한다.

를 조사하고, 이상없을 경우에만 다음 작업을 진행한다.

1. TASK 완료 시 — 노션 전송 (항상 실행)
작업 진행 결과(세부적이고 구체적으로 작성) + 다음 TASK 내용(세부적이고 구체적으로 작성)을 노션에 전송
채팅창에: 노션으로 작업결과와 다음 TASK를 보냈습니다
2. 승인이 필요한 경우 — 슬랙 알림
노션 전송과 별개로 슬랙에 승인요청 메시지 전송
채팅창에: 슬랙으로 승인요청을 보냈습니다
3. 코드 수정 — "제안"만 하고 직접 수정하지 않음
코드 수정이 필요하다고 판단되면, 실제 파일을 수정하지 않고 **수정 제안(코드 diff과 전체 코드안)**만 작성한다.
이 제안을 노션 updatecode 페이지에 전송한다: TASK명, 대상 파일명, 제안 코드 전체
ChatGPT가 파일을 직접 고치는 행위는 하지 않는다 (지금은 검토 단계이므로).
4. TASK 종료 후 — 무조건 대기
승인을 받았든 안 받았든, TASK가 끝나면 (노션/슬랙 전송까지 마친 후) 다음 TASK로 자동 진행하지 않는다.
5.다음 TASK 는 노션의 'AI 작업 관리' 페이지에 추가하고, 코드를 제안할때만 'updatecode' 페이지에 추가한다.
채팅창에서 사용자의 다음 지시가 올 때까지 멈춰서 기다린다.

현재 작업 대상은 EXP-001이다.
Notion Task의 지난 작업내용을 확인하고,
TASK시작시 ChatGPT채팅창에 TASK의 제목과 시작시간을 표시하라. 그리고 제목의 앞에 'N.***'형태로 TASK의 번호를 순서대로 인덱싱하라.

TASK를 완료하고 노션으로 작업결과와 다음 TASK를 보낼때, 완료한 TASK의 제목과 시작시간을 표시하라. 그리고 제목의 앞에 'N.***'형태로 TASK의 번호를 순서대로 인덱싱하라.
